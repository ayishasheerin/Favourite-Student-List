# Favourite-Student-List - Favourite Student List

A simple React application that allows users to manage their favourite students.

Features

Display a list of students

Add students to favourites

Prevent duplicate favourites

Remove students from favourites

Display the total favourite count

Navigate between pages using React Router

Technologies Used

React.js

Tailwind CSS

React Router DOM

Context API

Concepts Practised

useState

useContext

createContext

React Router

Array methods (map, find, filter, some)

Conditional rendering
